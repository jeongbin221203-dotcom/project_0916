수출 한 건에 나오는 서류는 **거의 늘 같은 다섯 개**이고, 거래 조건에 따라 몇 개가 더 붙습니다.

### 언제나 필요한 것

| 서류 | 만드는 사람 | 쓰임 |
| --- | --- | --- |
| **상업송장 (Commercial Invoice)** | 수출자 | 거래 내용·금액의 원본. 통관·대금 청구의 기준 |
| **포장명세서 (Packing List)** | 수출자 | 몇 박스에 무엇이 어떻게, 중량·치수. 검사·적재·클레임의 근거 |
| **수출신고필증 (수출면장)** | 관세청(관세사 대행) | 관세환급·부가세 영세율의 증빙 |
| **B/L 또는 AWB** | 선사·포워더 | 화물 인도 권리 |
| 계약서 / P·I (Proforma Invoice) | 수출자·바이어 | 조건의 근거. 분쟁 때 이것부터 봅니다 |

### 거래 조건에 따라 붙는 것

| 서류 | 언제 | 어디서 받나 |
| --- | --- | --- |
| **원산지증명서(C/O)** | FTA 특혜관세를 받을 때 | [대한상공회의소 무역인증](https://cert.korcham.net) (기관발급) / 관세청 — 협정마다 다르고, 한·미·한·EU 등은 **수출자 자율발급** |
| **보험증권(Insurance Policy)** | CIF·CIP 조건, L/C가 요구할 때 | 손해보험사(적하보험). 최소 **송장금액 110%**, 계약 통화로. **부보 범위가 조건마다 다릅니다** — CIF는 최소담보(ICC(C)), CIP는 최대담보(ICC(A))가 기본입니다 |
| **검사증명서(Inspection Certificate)** | 바이어·수입국이 요구할 때 | [SGS Korea](https://www.sgsgroup.kr) · [Bureau Veritas Korea](https://www.bureauveritas.co.kr) · [Intertek Korea](https://www.intertek.co.kr) 등 검정기관 |
| **식물검역증(Phytosanitary)·동물검역증** | 농산물·식물·목재 포장재(ISPM 15) | [농림축산검역본부](https://www.qia.go.kr) |
| **위생증명서(식품)** | 수입국이 요구할 때 | [식품안전나라](https://www.foodsafetykorea.go.kr) · 지방식약청 |
| **자유판매증명서(CFS)** | 화장품·식품 등 수입국 등록용 | 식약처 / 관련 협회 |
| **MSDS(물질안전보건자료)** | 화학품·배터리 등 | 제조사가 작성 — [화학물질정보처리시스템](https://kreach.me.go.kr) 참고 |
| **위험물 신고서·UN번호 확인** | 위험물 해상·항공 운송 | 포워더·선사(IMDG) / 항공은 IATA DGR |
| **선적통지서(Shipping Advice)** | 선적 직후 바이어 통지 | 수출자가 직접 작성 — FOB에서 바이어가 보험을 들 수 있게 **선적 즉시** 보냅니다 |

### 서류들 사이에서 반드시 일치해야 하는 값

여기가 어긋나면 통관이 막히거나 L/C 하자가 납니다.

- **품명(Description)** — 송장·포장명세서·B/L·C/O 모두 같은 표현
- **수량·포장 수·순중량/총중량**
- **금액·통화·인코텀즈 조건과 장소**
- **Shipper / Consignee / Notify**
- **HS부호** (송장·C/O·수출신고)
- **선적항·양륙항**, 선적일

### 우리 화면에서

**서류 작성**에서 값을 한 번 넣으면 상업송장·포장명세서를 만들고, **운송 계획**과 같은 값을 공유합니다. 기존 서류(PDF·사진)를 올리면 읽어서 칸을 채우고, 서류 사이에 값이 어긋나면 알려 드립니다. 빈 서식 PDF만 필요하시면 그것도 바로 내려받을 수 있습니다.
