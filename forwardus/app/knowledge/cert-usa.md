미국은 **통합 인증마크가 없고 품목마다 소관 기관이 다릅니다.** 승인·등록·신고가 없으면 CBP(세관)가 통관을 보류하거나 **수입거부(Refusal of Admission)** 처분을 합니다.

| 기관 | 대상 |
| --- | --- |
| **FCC** | 전파를 내보내는 기기 전부. 무선(Wi-Fi·BT·셀룰러·드론) → **Certification**, 디지털기기(노트북·LED·전원장치) → **SDoC** |
| **FDA** | 식품·음료·건강기능식품, 화장품, 의료기기, 의약품, 식품접촉물질, 레이저 등 방사선방출 제품 |
| **FTC** | 섬유·모직·모피 라벨, 세탁표시(Care Labeling), Made in USA 표시 |
| **CPSC** | 어린이제품(CPC·추적라벨), 일반 소비재(GCC), 매트리스·자전거·라이터 |
| **CBP** | 모든 수입품의 **원산지 표시**(19 U.S.C. 1304) |
| **OSHA / NRTL** | 작업장 전기설비. NEC를 채택한 지자체의 인허가 담당자(AHJ)가 NRTL 마크를 요구 |

> **UL은 연방 강제가 아닙니다.** 다만 OSHA·AHJ와 대형 유통사(Amazon·Walmart·Home Depot)가 UL/ETL 마크를 요구해 **사실상 필수**입니다. 예산에 넣으세요.

### 필요한 서류

**FCC Certification** — FCC 인정 시험소 시험성적서, 기술문서(블록도·회로도·동작설명·부품 리스트), 내외부 사진과 테스트 셋업 사진, 라벨 원고·부착 위치도, 사용자 매뉴얼(FCC 경고문구), 필요 시 RF 노출(SAR/MPE) 평가서, **FCC ID 신청**(Grantee Code 필요)

**FCC SDoC** — 시험성적서, **Compliance Information Statement**(미국 내 책임자의 이름·주소·연락처), 제품·매뉴얼·포장의 적합성 표시

**FDA**
- 식품: **식품시설 등록(FFR)**, **미국 대리인(U.S. Agent)**, 선적마다 **Prior Notice 확인번호**, FSVP 기록, 라벨(Nutrition Facts·알레르겐)
- 화장품: **MoCRA 시설 등록**, 제품 리스팅, **Responsible Person**, 안전성 입증자료, 성분 라벨
- 의료기기: 시설 등록, 기기 리스팅, 미국 대리인, 등급에 따라 **510(k)** 또는 **PMA**

**FTC·CPSC** — **RN 번호**, 섬유 혼용률·원산지·세탁표시 라벨, 어린이제품은 **CPSC 승인 시험소 성적서 + CPC + 추적라벨**

### 절차와 기간

- **FCC Certification**: 시험(1~3주) → 기술문서 → **TCB** 심사·FCC ID 발급(1~3주). 총 **4~8주**
- **FCC SDoC**: 시험 → 선언서 작성 → 통관 (TCB 심사 없음)
- **FDA 식품**: 시설 등록(무료·격년 갱신) → 미국 대리인 지정 → **선적 전 Prior Notice** (PNSI는 도착 15일 전, CBP ABI는 30일 전부터 제출 가능) → 통관
- **CPSC 어린이제품**: 제3자 시험 → CPC 발행 → 추적라벨 → 통관

한국에서 KTL·KTR·KTC·UL Korea(TCB·NRTL)·Intertek Korea(ETL)·SGS·TÜV 계열로 시험과 인증을 모두 진행할 수 있습니다.

### 2026년 확인할 것

- **FCC Covered List** — 국가안보상 지정된 통신장비(및 그 부품이 들어간 제품)는 Certification·SDoC 어느 경로로도 인증받을 수 없어 **수입·판매가 금지**됩니다. 중국산 모듈·칩셋을 쓰면 공급망을 반드시 확인하세요.
- **MoCRA** — 화장품 시설 등록·제품 리스팅 의무가 시행 중입니다. 화장품에는 Prior Notice 의무가 없고, 등록·리스팅 데이터로 선적이 스크리닝됩니다.

### 실무에서 자주 틀리는 것

1. **"미국은 인증이 없다"** — SDoC는 인증서가 없을 뿐 시험과 기술문서 보관 의무는 그대로입니다. 요구받으면 최종 수하인이 즉시 제출해야 합니다.
2. **SDoC 책임자는 미국 내에 있어야 합니다** — 한국 제조자는 될 수 없고 **수입자(importer of record)**가 책임자가 됩니다. 사전에 합의하고 매뉴얼·포장에 연락처를 넣으세요.
3. **UL을 선택으로 보고 건너뜀** — 유통사 입점과 시설 설치에서 막힙니다.
4. **시설 등록만 하고 Prior Notice 누락** — 둘은 별개이고 Prior Notice는 **선적 건마다** 냅니다. 빠지면 항구에서 억류됩니다.
5. **원산지 표시를 포장에만 함** — 최종 구매자가 볼 수 있도록 **물품 자체에 항구적으로** 표시해야 하고, 위반 시 10% marking duty가 붙을 수 있습니다.
6. **어린이제품에 GCC를 씀** — 12세 이하 대상은 **CPSC 승인 시험소 시험에 근거한 CPC**와 추적라벨이 필요합니다.
