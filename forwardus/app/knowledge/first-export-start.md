수출을 시작할 때 실제로 필요한 것은 생각보다 적습니다. **한 번만 해 두면 되는 일**과 **건마다 하는 일**을 나눠 보세요.

### 한 번만 해 두는 일

| 할 일 | 어디서 | 걸리는 시간 |
| --- | --- | --- |
| 사업자등록 (업태에 무역업 추가) | 세무서·홈택스 | 즉시~며칠 |
| **무역업고유번호** | 한국무역협회 | 신청 즉시 발급 (무료) |
| **통관고유부호** | 관세청 UNI-PASS | 신청 후 곧 |
| 외국환 거래용 계좌 개설 | 주거래은행 | 방문 |
| 전자무역 이용 등록(uTradeHub) | 무역협회 | 선택 |

> 무역업고유번호가 없어도 수출신고 자체는 가능하지만, **수출실적 관리와 지원사업 신청**에 필요합니다. 먼저 받아 두세요.

### 건마다 하는 일

품목 HS 확정 → 수출요건 확인 → 바이어 계약 → 부킹 → 수출신고 → 선적 → 서류 발송 → 대금 회수 → 환급·영세율

### 바이어를 찾는 현실적인 경로

- **KOTRA** 해외시장뉴스·지사화사업·수출상담회 (해외 무역관이 대신 발품을 팔아 줍니다)
- **무역협회** 바이어 매칭(tradeKorea), 전시회 참가 지원
- **글로벌 B2B 플랫폼** (Alibaba, Global Sources 등) — 문의는 많지만 진짜 바이어를 거르는 눈이 필요합니다
- **해외 전시회** — 비용이 크지만 성사율이 가장 높습니다. 지자체·중진공 참가비 지원을 먼저 찾으세요.

### 지원사업 — 먼저 찾아보면 비용이 절반이 됩니다

- **수출바우처** — 통번역·인증·마케팅·물류비를 바우처로 사용
- 중진공·지자체 **해외마케팅 지원**, 전시회 참가비 지원
- **무역보험료 지원**, 관세사 컨설팅 지원
- 신청 시기가 정해져 있으니(대개 연초) 미리 일정을 확인하세요.

### 처음 하는 사람이 가장 많이 겪는 세 가지

1. **인증을 확인하지 않고 납기를 약속** — 도착국 인증에 몇 달이 걸려 계약을 못 지킵니다.
2. **후불 조건을 덜컥 수락** — 물건만 나가고 돈이 안 들어옵니다. 선금 30%와 무역보험을 기본으로 잡으세요.
3. **서류 값이 서로 다름** — 송장·포장명세서·B/L의 품명·수량이 어긋나 통관이 멈춥니다.
