**NOM(Normas Oficiales Mexicanas)**은 멕시코 경제부(Secretaría de Economía) 표준국(DGN)이 관장하는 **강제 기술규격**입니다. 대상 품목은 NOM 적합인증서 없이는 **세관 통관 자체가 거부**되고, 통관 후 적발되면 벌금·판매금지·반송 명령까지 갑니다. (임의규격인 NMX와는 다릅니다.)

### 어떤 품목에 걸리나

적용 여부는 **HS 부호(fracción arancelaria) 단위**로 정해집니다. 대표 규격은 다음과 같습니다.

- **NOM-001-SCFI-2018** 전자기기 안전 (TV·오디오·PC·어댑터·휴대폰 등). 2020년 5월 발효, 구 NOM-019-SCFI를 흡수
- **NOM-003-SCFI** 전기제품 안전 (가전·전동공구)
- **NOM-024-SCFI-2013** 전자·전기·가전의 상업정보(포장·설명서·보증서) 표시
- **NOM-050-SCFI** 개별 라벨링 규격이 없는 **모든 일반 제품**의 기본 상업정보 라벨
- **NOM-051-SCFI/SSA1** 포장식품·음료 영양표시 및 전면 경고표시(sellos)
- **NOM-004-SCFI** 섬유·의류 라벨링 / **NOM-015-SCFI** 완구 / **NOM-141** 화장품 라벨
- **NOM-xxx-ENER** 에너지효율(CONUEE 소관)

> 한 제품에 **안전 NOM + 상업정보 NOM + 에너지효율 NOM이 동시에 세 개** 걸리는 경우가 흔합니다. HS 부호로 SNICE·표준 카탈로그에서 직접 조회하세요.

### 필요한 서류

- 신청서(Solicitud), **시험성적서 / DICTAMEN** (멕시코 공인시험소, 통상 견본 3개 제출)
- 기술문서 — 회로도, 부품 배치도, 주요 부품 리스트, 사양서
- 제품 사진 또는 카탈로그
- **스페인어** 제품 매뉴얼(instructivo), **라벨 원고(etiqueta)**, 보증서(póliza de garantía)
- 라벨에 들어갈 항목: 수입자명·주소·**RFC(세무번호)**, 원산지, 정격, 경고문구
- HS 부호·원산지·최종사용자 정보, 제조자·공장 주소
- 멕시코 **수입자의 법인 서류**(RFC, 정관, 위임장), **수입자 등록(Padrón de Importadores)** 증빙
- 식품·화장품·의료기기는 **COFEPRIS** 위생등록, 자유판매증명서(CFS), 성분표

### 어디서 발급하나

| 역할 | 기관 |
| --- | --- |
| 감독 | 경제부(SE) / 표준국(DGN) — 근거법은 2020년 시행 **품질인프라법(LIC)** |
| 인정 | **EMA** (인증기관·시험소·검증단 인정) |
| 인증(OC) | **ANCE**(가전·전기), **NYCE**(전자·통신·IT), IMNC, NORMEX, UL, Intertek |
| 식품·화장품·의료기기 | **COFEPRIS** |
| 농축수산·검역 | SENASICA |
| 통신기기 전파 | 2025년 7월 개편으로 구 IFT 기능이 **CRT·ATDT**로 이관 (NOM과 별개) |
| 한국 창구 | **KTC**(멕시코 NOM 전담), KTR, UL Korea, TÜV SÜD Korea, Intertek Korea, Nemko Korea |

국내에서 **IEC/CB 성적서**를 미리 받아 두면 현지 시험 범위를 줄일 수 있습니다.

### 절차와 기간

1. **NOM 식별** (1~2주) — HS 부호로 적용 규격 확정
2. **멕시코 현지 신청인 확보** — 인증서는 **멕시코 법인(수입자·제조자·판매자) 명의로만** 발급됩니다. 한국 제조자는 현지 대리인·수입자를 통해 신청하고, 이후 **소유권 확장(Extensión de titularidad)**으로 사본 인증서를 받습니다
3. **시험** (3~8주) — 견본 3개 → DICTAMEN
4. 인증기관 서류 심사
5. **인증서 발급** (약 2주)
6. **라벨 제작·부착** — 통관 전 부착이 원칙. 미부착 시 보세창고 재라벨링 비용·지연
7. **통관** — 수입신고서(pedimento)에 인증서 사본 첨부

**전체 6~20주.** 비용은 제품군·시험 항목별 편차가 커서 공시 요율표가 없습니다(인증기관·국내 대행기관 견적 필요). 유효기간은 전기·전자의 경우 통상 1년·매년 갱신이 일반적이나 규격·방식별로 다르므로 확인이 필요합니다.

### 2026년 바뀐 것

- **2026년 7월 1일 시행** — 휴대폰(HS 8517.13.01 / 8517.14.91 / 8517.18.99)의 특송·소포 간이통관 면제가 폐지되어, 수입 시 **NOM-001-SCFI-2018 + NOM-024-SCFI-2013 증명이 필수**가 되었습니다. (8413.60.01 잠수펌프는 대상에서 제외)
- **NOM-051** 전면 경고표시 2단계가 **2027년 말까지 연장**, 3단계는 2028년 1월 시작으로 조정되었습니다.
- 2021년부터 NOM-051 대상은 EMA 인정 + COFEPRIS 승인 **검증단(UI)**의 라벨 평가를 반드시 거칩니다.

### 실무에서 자주 틀리는 것

1. **인증서가 수입자 명의**라는 점 — 수입자를 바꾸면 새로 받거나 소유권 확장을 해야 합니다. 현지 파트너와 틀어지면 인증서가 인질이 됩니다. **계약서에 인증서 소유권·이전 조항**을 넣으세요.
2. **안전 NOM만 받고 라벨 NOM을 빠뜨림** — NOM-001을 받아도 NOM-024·NOM-050이 없으면 통관이 멈춥니다. 별개 트랙입니다.
3. **스페인어 라벨·매뉴얼·보증서를 선적 직전에 준비** — 라벨 원고는 인증 신청 때 함께 승인받으세요.
4. **CB 성적서가 있으니 면제된다고 기대** — 범위를 줄여 줄 뿐, 멕시코 시험소의 DICTAMEN은 따로 필요합니다.
5. **갱신 누락** — 만료되면 재고가 있어도 추가 선적분이 막힙니다. 만료 2~3개월 전에 착수하세요.
6. **수입자의 Padrón de Importadores에 해당 품목군이 없음** — 인증이 있어도 통관이 안 됩니다.
