## 먼저 알아 두실 것

**법률 자문이 아닙니다.** 아래는 실무에서 자주 걸리는 자리를 정리한 것이고,
최종 계약서는 변호사 검토를 받으셔야 합니다.

서류는 우리 화면에서 만들어 드리는데, **돈을 떼이거나 물리는 자리는 계약서**입니다.
서류가 다 맞아도 계약서에 "바이어가 언제든 해지할 수 있다"가 들어 있으면
실어 놓고 물립니다. 그 문장은 송장에도 B/L에도 안 나옵니다.

## ① 있어야 할 것 — 필수조항 14

빠지면 다툼이 났을 때 기댈 곳이 없습니다.

| 조항 | 왜 |
|---|---|
| **물품 명세** | 규격이 없으면 바이어가 임의 기준으로 불합격을 줍니다 |
| **가격조건 (Incoterms 2020)** | 조건 + **지정장소** + 판(2020)을 한 줄에 다 적습니다 |
| **결제조건** | 언제 L/C를 여는지, 은행 수수료는 누가 내는지까지 |
| **선적조건** | 선적 기일 · 분할선적 · 환적을 **L/C와 같은 말로** |
| **검사·품질** | 선적지 검사를 최종으로, 도착 후 며칠 안에 통보 없으면 인수 간주 |
| **보험** | CIF·CIP일 때. 110% · 계약 통화 · 담보 범위 |
| **불가항력** | 사유 목록에 **수출규제·제재·원공급사 불이행**을 꼭 넣으세요 |
| **준거법** | 한국법 우선. CISG 적용 여부도 명시 |
| **분쟁해결(중재)** | 중재지 · 기관 · 규칙 · 언어 네 가지 |
| **소유권 유보** | 소유권은 **대금 완납 시**, 위험은 인코텀즈대로 — "인도 시 소유권 이전"은 유보가 아닙니다 |
| **포장·화인** | 수출 포장 기준과 화인(마크)을 적어 두면 파손 클레임을 막습니다 |
| **비밀유지** | 원가·도면이 오가면 **양쪽 모두**에 걸리게 |
| **수량 과부족 허용** | 벌크·원단은 ±5% 같은 허용 범위를 L/C와 같게 |
| **계약 변경·통지** | 변경은 **양쪽 서명 서면**으로만, 통지는 정한 주소로만 |

**중재를 소송보다 먼저 보세요.** 외국 법원 판결은 상대국에서 집행이 어렵지만,
중재 판정은 뉴욕협약으로 170여 개국에서 집행됩니다.

## ② 챙기면 이로운 것 — 이익조항 15

없어도 계약은 되지만, 있으면 우리가 덜 잃습니다.

- **지연이자** — 일할 이자 + **연체 중 선적 중단권**을 한 쌍으로
- **가격 조정** — 환율·원자재가 몇 % 움직이면 재협의, 안 되면 취소
- **책임 한도** — 송장 금액 상한 + 간접손해 배제
- **클레임 기한** — "도착 후 15일 안에 서면 통지, 넘기면 포기로 본다" (법원이 유효로 본 꼴입니다)
- **신용장 개설 기한** — 선적 몇 일 전까지, 안 열리면 해제·재판매
- **바이어의 상계 금지** — 클레임을 이유로 대금을 깎아 보내지 못하게
- **수출허가 조건** — 허가를 못 받으면 면책 (전략물자면 필수)
- **금형·도면 소유권**, **바이어 도면의 권리 보증**, **해지 시 재고·금형 인수**
- **최소 주문·취소 수수료** — 독점을 줄 때는 최소 물량을 반드시
- **CISG 적용·배제 명시**, **대리점 보호법 확인**, **가공 손모율·잔량 처리**(가공계약)

## ③ 있으면 위험한 것 — 독소조항 55

있으면 우리가 크게 물립니다. 지우거나 고쳐 달라고 하세요. 수출자가 먼저 묻는
**"돈을 못 받는가 · 얼마나 물리는가"** 순서로 묶었습니다.

| 묶음 | 대표 조항 |
|---|---|
| **① 대금을 못 받거나 늦게 받음** | 재판매 대금 조건부 결제 · 신용장 소프트 조항(바이어 서명 서류) · 선적서류 원본을 대금 전에 · **바이어 서명이 있어야 지급 시작** · 바이어 마음대로 상계 · 챠지백 · **청구만 하면 지급되는 이행보증** |
| **② 상한 없는 배상** | 우리가 모든 손해를 상한 없이 배상 · 간접손해·영업손실까지 · 상한 없는 지연배상금 · 대체 구매 차액 무한 부담 · 기간 없는 하자보증 · 리콜 비용 전가 |
| **③ 품질·검사** | 합격 판정을 바이어 단독으로(수입국 검사기관 "final") · 불합격 시 전량 반품 · 전수검사 · 인증·PSI 비용 전가 |
| **④ 계약을 끊거나 바꿈** | 바이어 일방 해지 · **조금만 늦어도 바로 해제** · 바이어가 혼자 조건 변경 · **바이어 발주서·구매약관이 우선** · 자동 연장 |
| **⑤ 무역조건·비용 전가** | 인코텀즈와 어긋나는 비용 문구 · DDP인데 현지 수입자가 될 수 없음 · 관세 인상분 흡수 · EU EPR 분담금 |
| **⑥ 기술·지재권·영업 제한** | 도면·기술 제공(중국) · 상표를 바이어 명의로 · 개발 결과물·금형 권리 이전 · 넓은 경업금지 · 최혜대우 가격 |
| **⑦ 분쟁 해결·언어** | 상대국 법원 전속관할 · 중국 국내 중재 전속 · 미국 배심재판 · **상대 언어본 우선** · **불가항력이 바이어에게만** |
| **⑧ 제재·대리점·가공** | 제재 보증·면책 · 재수출 통제 없음 · 걸프 등록 대리인 · EU 상업대리인 보상 |

굵은 것은 **실제 판결·중재에서 매도인이 진 문구**로 넣은 조항입니다. 예를 들어
러시아 바이어가 시운전 확인서 서명을 거부하며 대금을 미뤄, 한국 매도인이
대법원까지 가서야 받았습니다(대법원 2025.3.27. 2021다242185).

**방향을 보세요.** 같은 문장도 매도인·매수인이 바뀌면 우리에게 유리합니다.
"바이어가 대금을 늦게 내면 하루 1%"는 독소가 아니라 우리를 지키는 조항입니다.
반대로 "양쪽 모두 언제든 해지할 수 있다"는 바이어도 끊을 수 있어 위험합니다.

## 특히 조심할 짝

**중재 조항과 전속관할 조항이 같이 들어 있는** 계약서가 꽤 많습니다.
서로 모순이라, 다툼이 나면 "어디서 다툴지"부터 다시 싸웁니다. 하나만 남기세요.

**우리 계약서와 바이어 발주서(PO)가 따로 오가는** 거래도 조심하세요. PO에
"구매약관이 우선한다"가 있으면 우리가 넣은 책임 한도·중재가 밀려납니다.
PO의 다른 조건은 받는 즉시 서면으로 거절해 두세요.
