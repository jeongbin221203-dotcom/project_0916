## 먼저 알아 두실 것

**법률 자문이 아닙니다.** 아래는 실무에서 자주 걸리는 자리를 정리한 것이고,
최종 계약서는 변호사 검토를 받으셔야 합니다.

서류는 우리 화면에서 만들어 드리는데, **돈을 떼이거나 물리는 자리는 계약서**입니다.
서류가 다 맞아도 계약서에 "바이어가 언제든 해지할 수 있다"가 들어 있으면
실어 놓고 물립니다. 그 문장은 송장에도 B/L에도 안 나옵니다.

## ① 있어야 할 것 — 필수조항 10

빠지면 다툼이 났을 때 기댈 곳이 없습니다.

| 조항 | 왜 |
|---|---|
| **물품 명세** | 규격이 없으면 바이어가 임의 기준으로 불합격을 줍니다 |
| **가격조건 (Incoterms 2020)** | 조건 + **지정장소** + 판(2020)을 한 줄에 다 적습니다 |
| **결제조건** | 언제 L/C를 여는지, 은행 수수료는 누가 내는지까지 |
| **선적조건** | 선적 기일 · 분할선적 · 환적을 **L/C와 같은 말로** |
| **검사·품질** | 선적지 검사를 최종으로, 도착 후 며칠 안에 통보 없으면 인수 간주 |
| **보험** | CIF·CIP일 때. 110% · 계약 통화 · 담보 범위 |
| **불가항력** | 사유 목록에 **수출규제**를 꼭 넣으세요 |
| **준거법** | 한국법 우선. CISG 적용 여부도 명시 |
| **분쟁해결(중재)** | 중재지 · 기관 · 규칙 · 언어 네 가지 |
| **소유권 유보** | 소유권은 대금 완납 시, 위험은 인코텀즈대로 |

**중재를 소송보다 먼저 보세요.** 외국 법원 판결은 상대국에서 집행이 어렵지만,
중재 판정은 뉴욕협약으로 170여 개국에서 집행됩니다.

## ② 챙기면 이로운 것 — 이익조항 6

없어도 계약은 되지만, 있으면 우리가 덜 잃습니다.

- **지연이자** — 일할 이자 + **연체 중 선적 중단권**을 한 쌍으로
- **가격 조정** — 환율·원자재가 몇 % 움직이면 재협의, 안 되면 취소
- **책임 한도** — 송장 금액 상한 + 간접손해 배제
- **수출허가 조건** — 허가를 못 받으면 면책 (전략물자면 필수)
- **금형·도면 소유권** — 비용을 바이어가 냈더라도 우리 것
- **최소 주문·취소 수수료** — 독점을 줄 때는 최소 물량을 반드시

## ③ 있으면 위험한 것 — 독소조항 10

있으면 우리가 크게 물립니다. 지우거나 고쳐 달라고 하세요.

| 조항 | 계약서에서 이렇게 보입니다 | 어떻게 되나 |
|---|---|---|
| **무제한 손해배상** | without limitation / any and all | 1만 달러 건에서 영업손실 전부를 뭅니다 |
| **일방적 해지권** | terminate ... for convenience | 생산 착수 뒤 해지 통보를 받습니다 |
| **상대국 전속관할** | exclusive jurisdiction | 이겨도 집행에 몇 년 걸립니다 |
| **재판매 조건부 결제** | after the Buyer receives payment | 안 팔리면 영영 못 받습니다 |
| **무기한 하자보증** | warrants ... without time limitation | 3년 전 선적분으로 전량 교체 요구 |
| **상한 없는 지연배상금** | liquidated damages ... per day | 대금보다 배상금이 커집니다 |
| **인코텀즈와 어긋나는 문구** | notwithstanding the trade term | FOB 값 받고 DAP 책임을 집니다 |
| **자동 연장 + 긴 예고** | automatically renewed / 180 days | 손해 나는 조건에 1년 더 묶입니다 |
| **최혜대우(MFN) 가격** | no less favourable | 신규 판촉가를 소급해 물어 줍니다 |
| **전량 반품·비용 전가** | reject the entire shipment | 1% 불량으로 컨테이너가 돌아옵니다 |

## 특히 조심할 짝

**중재 조항과 전속관할 조항이 같이 들어 있는** 계약서가 꽤 많습니다.
서로 모순이라, 다툼이 나면 "어디서 다툴지"부터 다시 싸웁니다. 하나만 남기세요.

## 올려서 확인하실 수 있습니다

찾아 드리고, 붙여 쓸 조항 문안을 내려받으실 수 있습니다.
