## 검사 안에 적어 둔 "알고 있는 것"

몇몇 검사는 **하나씩 열어 확인한 무해한 것**을 목록으로 갖고 있습니다
(`KNOWN`, `KNOWN_ATTRS`, `NOT_REAL`). 새로 생긴 것만 걸리게 하려는 것입니다.
목록에 더할 때는 **왜 무해한지 주석으로 남겨 주세요.** 그냥 지우면
다음 사람이 같은 것을 또 조사합니다.
