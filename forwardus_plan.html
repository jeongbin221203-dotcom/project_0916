Forwardus
수출자를 위한 종합 물류 AI 서류 매니저

물류 전담 인력이 없는 중소기업과 1인사업자가 운송 계획, 무역서류, 화물 추적을 한 곳에서 처리하도록 돕는 웹 서비스.

1배경

소규모 수출 실무자는 매 건마다 같은 세 가지 문제를 반복해서 겪는다.

단계실무자의 질문
운송 계획해상/항공, FCL/LCL 중 무엇을 고르나. 납기에 맞추려면 언제 출고해야 하나.
서류·통관어떤 서류가 필요한가. 서류 간 수량·중량·금액이 맞는가.
실제 운송화물이 지금 어디 있나. ETA가 바뀌었나. 납기에 영향이 있나.

2비전

소규모 수출기업을 위한 Export Operating System 한 번 입력한 데이터를 견적, 서류, 운송, 추적, 분석까지 다시 입력하지 않고 이어서 쓴다.
  1. Route·Cargo 입력
  2. 운송 계획
  3. 스케줄 선택
  4. Shipment 생성
  5. 무역서류
  6. Booking·출항
  7. Tracking
  8. ETA 모니터링
  9. 이력·분석

3대상 사용자

  • 수출 경험이 적은 중소기업
  • 물류 담당자가 없는 소규모 제조업체
  • 해외 판매를 시작하는 1인사업자
  • 해외 B2B 거래를 하는 스타트업
  • 반복적인 소량 수출을 처리하는 실무자

4핵심 가치

한 번 입력

견적 단계에서 넣은 정보를 서류, 운송, 추적에 그대로 재사용한다. 같은 값을 두 번 입력하지 않는다.

Shipment 단위 관리

화물, 스케줄, 서류, 이벤트, 비용, 결제를 하나의 Shipment ID로 묶는다.

계산은 코드, 설명은 AI

운임·CBM·자금 계산과 규정 판정은 코드와 데이터가 맡는다. AI는 결과를 풀어서 설명한다.

출처 표시

모든 데이터에 api / mock / manual 등 출처를 남기고, Mock 데이터를 실제 데이터처럼 보여주지 않는다.

5주요 기능

Core제품의 중심 기능

운송 계획

Shipment Planning

화물 정보와 목적지를 받아 운송 방식과 스케줄을 고르게 한다.

  • Route Setup — 출발 희망일, SEA(FCL/LCL)/AIR, 출발·도착 항구 자동완성
  • Cargo 계산 — CBM, Revenue Ton, Chargeable Weight, 컨테이너 수량
  • 스케줄 조회 — 선사/항공편, ETD·ETA, 운송기간, 운임. 추천·최저가·최단순 정렬
  • 역산 플래너 — Buyer 요청일에서 거꾸로 ETA, ETD, 출고 준비일 계산

서류·통관

Trade Document Center

Shipment에 이미 있는 값으로 무역서류를 작성하고 서류 간 불일치를 잡는다.

  • 자동 작성 — Commercial Invoice, Packing List, Proforma Invoice, Shipping Instruction, Booking Request
  • 교차 검증 — 수량, 중량, 금액, 통화, Incoterms, HS CODE, Consignee, POL/POD 비교
  • 상태 관리 — draft → generated → validated → final

HS Code 검색

HS Code Search/Recommand

입력한 물품에 따른 적합한 HS Code를 제시해준다.

  • HS Code 적합도 표시 — 정렬 기준에 따른 HS Code 적합도 추천 기능
  • 관세 비교 — 수입국 기준에 따른 관세 협정 등 분석하여 제시
  • 필요 서류 안내 — 선택한 물품에 따른 규정 및 필요 서류 안내
