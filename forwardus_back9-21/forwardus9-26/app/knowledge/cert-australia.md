호주의 강제 인증은 **RCM(Regulatory Compliance Mark)**입니다. 마크는 하나처럼 보이지만 실제로는 **전기안전(EESS)**과 **전파·통신(ACMA)**이라는 **두 개의 별개 제도**를 함께 나타냅니다. RCM이 없으면 통관보다 **호주 내 판매·전시·광고가 불법**이 되어 벌금·등록 말소·강제 리콜 대상이 됩니다.

### ★ 한국 기업은 직접 등록할 수 없습니다

EESS 등록은 법적으로 **ABN(호주사업자번호) 또는 뉴질랜드 IRD 번호를 가진 법인**만 가능하고, **EESS는 대리인(agent) 제도를 금지**합니다. 호주 수입자가 **Responsible Supplier**가 되거나 현지법인을 세워야 합니다.
**수입자를 바꾸면 같은 제품이라도 새 수입자가 처음부터 다시 등록**해야 합니다. 유통 파트너 선정이 곧 인증 위험입니다.

### 어떤 품목에 걸리나

- **EESS(전기안전)** — 가정용·유사용도 전기기기. 위험도에 따라 **Level 1(저)/2(중)/3(고)**
  - Level 1: 등록 자율(권장), 표준 적합 증거 + RCM
  - **Level 2: 등록 의무 + Compliance Folder 필수**
  - **Level 3: 등록 의무 + Certificate of Conformity 필수**
- **ACMA(전파·통신)** — **EMC, 무선, 통신, EME(전자파 인체노출)** 4개 영역
- 대표 규격 — **AS/NZS 4417.1·4417.2**(RCM 마킹 자체), **AS/NZS 3820**(필수 안전요구사항의 기반). 적용 순서는 ① 기기 전용 AS/NZS + 3820 → ② AS/NZS 동등품이 없으면 IEC + 3820 → ③ 둘 다 없으면 3820 단독
- 식품은 **FSANZ 식품기준코드** + 수입식품 검사제도

### 필요한 서류

| 서류 | 비고 |
| --- | --- |
| **Responsible Supplier Declaration** | 호주/NZ 법인 책임자 서명 |
| **Compliance Folder** | Level 2 필수. **영문** 성적서 포함. 등록 종료 후 **5년 보관**, 요청 시 **10 영업일 내 제출** |
| **Certificate of Conformity** | **Level 3 필수.** RECS 인증기관 또는 규제당국 발급 |
| **Test Report (영문)** | 한글 성적서는 인정되지 않습니다 |
| Import Permit / Phytosanitary / Fumigation / Packing Declaration | 생물보안·목재포장 관련 (BICON 판정에 따라) |
| **Certificate of Origin (KAFTA)** | 자율증명 |

### 어디서 받나

**EESS 공인 인증기관(RECS) 8곳** — Certification Body Australia, EESS Conformity Certification Services, **Global-Mark**, **UL International New Zealand**, **SAA Approvals**, Oz Cert, **SGS Australia**, **TÜV Rheinland Australia**.
⚠️ **Comtest·Intertek·KTL/KTC/KTR은 이 목록에 없습니다.** UL은 뉴질랜드 법인 명의로만 등재돼 있습니다.

인정기구는 **JAS-ANZ**, 표준 구매는 Standards Australia, 생물보안은 **DAFF**(수입조건 조회 **BICON**)입니다.

**한국 창구** — **KTR**은 영문 사이트 해외인증 대상국에 호주를 명시합니다(RCM 범위는 개별 문의). **KTL**은 호주 명시가 없어 문의가 필요합니다. 실무에서는 **SGS·TÜV Rheinland·UL의 한국 지사 → 호주 법인 연계**가 현실적입니다. **KNOWTBT**(knowtbt.kr)에서 국가별 제도를 조회할 수 있습니다.

### 절차와 수수료

1. 품목 판정(in-scope 여부, ACMA 대상 여부) → Level 결정
2. 적용 표준 확정 → 3. **영문** 시험성적서
4. **Certificate of Conformity**(Level 3) — SAA Approvals 공표 목표는 **인증서 발급 5일**(전체 기간이 아닙니다)
5. **Responsible Supplier 등록**(호주/NZ 법인이 EESS Platform에서)
6. 기기 등록(Level 2·3) → 7. Compliance Folder 구성·보관
8. **RCM 마킹**(AS/NZS 4417.1·.2에 따라 모델 식별 표시 근처 외부 표면)
9. ACMA 대상이면 **SDoC** 작성 + ACMA용 EESS 등록(무료)

**수수료(2026년 7월 1일 적용, GST free)** — Responsible Supplier 등록 **AUD 239.74/년**, Level 2·3 기기 등록 **89.85(1년) / 179.70(2년) / 449.25(5년)**, ACMA 전용 Responsible Supplier 등록 **무료**.
Level 3의 등록 기간은 **보유한 Certificate of Conformity의 유효기간을 넘을 수 없습니다.** RECS·DAFF 수수료와 단계별 소요기간은 공표된 값이 없어 확인이 필요합니다.

### FTA

**한·호주 FTA(KAFTA)는 2014년 12월 12일 발효**했습니다. **원산지증명은 자율증명**이라 한국 수출자·생산자가 직접 작성한 증명서로 특혜관세를 신청할 수 있습니다. 서식과 원산지결정기준은 관세청 FTA 포털에서 확인하세요.

### 실무에서 자주 틀리는 것

1. **"우리가 RCM을 받으면 된다"** — 위의 등록 주체 제약을 보세요. 가장 치명적인 오해입니다.
2. **인증서를 판매 허가로 오해** — 공식 문구 그대로 *"the certificate alone does not give authority to sell."* 등록 + 마킹이 모두 있어야 합니다.
3. **EESS와 ACMA를 하나로 착각** — 제도가 둘입니다. 전기안전만 처리하고 EMC/무선 SDoC를 빠뜨리는 사례가 잦습니다.
4. **Compliance Folder가 없거나 한글** — Level 2 필수이고 **영문**이어야 하며 10 영업일 내 제출할 수 있어야 합니다.
5. **NSW를 EESS와 같게 처리** — EESS 참여는 QLD·VIC·WA·TAS이고 SA·NT·ACT는 전환 중이며 **NSW는 기존 체계를 유지**합니다. 전국 유통이면 양쪽을 봐야 합니다.
6. **목재 포장재·BMSB 시즌 간과** — 전기제품이라도 팔레트 ISPM 15 처리와 Packing Declaration이 빠지면 국경에서 지연됩니다. 시즌 대상국 분류는 해마다 바뀌니 **DAFF에서 확인**하세요.
