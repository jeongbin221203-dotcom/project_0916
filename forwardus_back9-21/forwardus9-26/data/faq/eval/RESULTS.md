## E. 측정 방법

```bash
python -m scripts.faq_eval --mode before --llm real --sample 30 --tag n30   # 개선 전(실제 API)
python -m scripts.faq_eval --mode after  --llm real --sample 30 --tag final # 개선 후(실제 API)
python -m scripts.faq_eval --mode after  --llm stub --llm-latency 0 --tag v1
python -m scripts.faq_eval --mode after  --llm stub --llm-latency 0 --warm --tag v1
python -m scripts.faq_bench --threads 1 ; python -m scripts.faq_bench --threads 8
```

결과 원본은 `results/*.json` 에 질문별 경로·점수·시간까지 그대로 들어 있습니다.

## F. 아직 재지 못한 것

- **TTFT(첫 응답 시간)**: 이 앱은 스트리밍을 쓰지 않습니다. 답이 다 만들어진 뒤 한 번에
  옵니다. 그래서 TTFT와 전체 응답 시간이 같습니다. 스트리밍을 붙이기 전에는
  "첫 글자가 빨라졌다"고 말할 수 없습니다.
- **여러 요청이 동시에 올 때의 전체 응답 시간**: 위 C는 검색 구간만입니다. AI를 포함한
  동시 부하 시험은 돈과 호출 한도 때문에 하지 않았습니다.
- **답변 정확성·완전성의 사람 평가**: 채점 기준(expected_points)은 질문마다 적어 두었지만,
  사람이 150개를 읽고 매긴 점수는 없습니다. 자동 지표(경로·검색)만 쟀습니다.
